# Career Diya Design System v2

Status: Implemented

Career Diya v2 consolidates the visual and UX language into one product system rather than page-specific treatments.

## Surface hierarchy

1. **Paper** (`#fbfbf8`) — default page canvas, forms, dashboards, result surfaces.
2. **Mural** (`#fdf9f1`) — one hero band per page; decorative artwork stays at the edges and never sits underneath text.
3. **Card** — consistent white content surface with one radius, border and hover behavior.
4. **Navy** (`#151827` / `#213A8F`) — decisive actions, journey anchors and closing/footer surfaces.

## Mural recipe

Every mural band uses the same five-layer stack:

- flat warm paper base
- 2–3 soft blooms
- low-ink diagonal hatch
- 0–2 outline shapes in empty corners
- a text-column legibility scrim

Home uses the fullest expression; inner page heroes use a quieter two-bloom treatment. Body sections, forms and dashboard surfaces remain plain paper.

## Journey grammar

Core product language remains:

**Understand → Explore → Decide → Act**

Assessment now presents its three options as a deliberate progression rather than three equal standalone products.

## Shared component language

- Poppins throughout
- buttons at weight 650
- title-case visible button labels
- consistent profile/avatar control
- consistent nav and active-page indicator
- shared card radius, border and shadow behavior
- shared navy closing/footer surface

## Behavioral rule

The visual system should explain *why* a surface looks different. Decorative changes without product meaning should not be introduced per-page.
