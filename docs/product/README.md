# Product docs

Product assets — distinct from engineering docs (`../architecture/`, `../../ENGINEERING_HANDBOOK.md`)
because they have different authors, audiences, and change cadence.

Lives here: the Founder Edition (the source of truth this whole system distills), the PRD, personas,
user journeys, the EVOLVE framework narrative, GTM/positioning, and the five MVP validation questions.

> Note the boundary: product docs evolve under the **Design Freeze** (free to iterate). When a product
> change implies a schema/API change, that crosses into the **Contract Freeze** and goes through the
> governed amendment path (handbook §1). Editing a doc here does not, by itself, change the contract.
