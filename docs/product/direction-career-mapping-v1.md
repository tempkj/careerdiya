# Career Diya Direction → Career Library Mapping v1.1

## Purpose

The free exploration engine recommends broad Career Diya directions. This mapping resolves each direction to exact canonical Career Library career names. A direction itself is never treated as a Career Library career URL.

## Status model

- **Canonical status: Verified** — exact name exists in the supplied Career Library catalogue/evidence.
- **Relationship status: Curated** — Career Diya groups the career under the direction as a primary fit.
- **Relationship status: Provisional** — plausible cross-direction relationship that should be reviewed later.

## Linking rule

Never derive a Career Library URL from a broad direction label. First resolve an exact canonical career entity from the mapping/catalogue. The Career Library detail URL is then generated from that canonical career name using the confirmed partner URL pattern `/global-career-library/in/{career-name}/en-IN`; explicit `libraryPath` values override generation when already known.
